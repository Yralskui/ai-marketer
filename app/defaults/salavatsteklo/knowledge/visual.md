## Фирменные цвета: основная палитра
Основной цвет бренда — Petrol: тёмно-синий с зелёным оттенком, Pantone 3155 C, HEX #196C7F
(CMYK 84/38/36/21, RGB 25/108/127). Это основной цвет логотипа. Он выглядит спокойно и
благородно и ассоциируется с прозрачностью, чистотой, прочностью и надёжностью.
Полная основная палитра (стр. 21–22):
- Pantone 7541 C — #DDE1E1 (самый светлый серый);
- Pantone 5513 C — #C1D0D3 (светлый серо-голубой);
- Pantone 3155 C — #196C7F (Petrol, основной);
- Pantone 2216 C — #285055 (тёмный сине-зелёный).
Все материалы бренда делаются только в этих цветах. На шкале Petrol в брендбуке показаны
оттенки от 20 % до затемнения +40K. Любые другие цвета вместе с фирменными использовать запрещено.

## Фирменные цвета: дополнительные
Дополнительные цвета (стр. 23) — только для презентаций, графиков, диаграмм, таблиц и
отчётов, а также для особого акцента:
- Pantone 310 C — #8ACCD9;
- Pantone 7712 C — #0094A8;
- Pantone 3282 C — #289389;
- Pantone 2216 C — #E5917F;
- Pantone 2344 C — #DB6051;
- Pantone 1795 C — #D33835.
(Номера Pantone приведены так, как они подписаны в брендбуке; HEX — точные значения.)
На носителях бренда дополнительные цвета применяются только по согласованию с ответственным
за утверждение макетов. В картинках для постов их не использовать: только в инфографике.

## Шрифты
Основная пара (стр. 25):
- Intro Black — заголовки, слоганы, важные сообщения;
- Avenir Next Cyr — основной текст, много начертаний.
Дополнительный (стр. 26): Segoe UI Black для заголовков и Segoe UI Regular для текста, когда
основные шрифты технически недоступны: деловые документы, переписка, экранные презентации.
Использовать Segoe для рекламных макетов строго запрещено. На сгенерированных картинках текст
лучше не размещать вообще.

## Фирменный паттерн
Паттерн (стр. 29–31) состоит из кругов и округлых форм («таблеток»). Он передаёт чувство
общности, безопасности, искренности и единства и делает бренд узнаваемым. Правила:
- только в основных фирменных цветах (#196C7F, #285055, #C1D0D3, #DDE1E1); при невозможности
  цвета — монохром;
- кадрировать можно с любой стороны, но линия обреза должна проходить по центру окружности;
- в детали паттерна можно поместить растровое изображение, но одно изображение на весь паттерн;
- нельзя ставить отдельные картинки в каждую деталь и менять цвета деталей.

## Дополнительные графические элементы
Стр. 32: узкая прямая линия фирменного цвета (Pantone 3155 C); узкая белая линия на фоне
фирменного цвета; широкая линия фирменного цвета; широкая линия с градиентом от Petrol к
Pantone 310 C (#8ACCD9). Есть фирменные пиктограммы в линейном стиле (лампочка, солнце,
рамка, батарея), но использовать можно только оригинальные макеты компании.

## Фотостиль: общие требования
Стр. 33. Фотография работает на имиджевую и эмоциональную часть макета. Требования:
- профессиональное качество, реалистичность, оригинальные ракурсы, хорошая цветопередача;
- жанр зависит от идеи: предметная съёмка, общий вид здания, архитектурные элементы,
  урбанистические пейзажи, производство, жизненные ситуации;
- допускается отрисовка 3D-изображений стеклянных продуктов;
- избегать оптических искажений стекла (эффект линзы);
- стекло на фото чистое: без пятен и подтёков;
- запрещены фото с сексуальным подтекстом, агрессией, карикатурные, неестественные и с явными
  признаками монтажа.

## Фотостиль: жанры снимков
Стр. 34.
- Архитектурные объекты: здания показывают применение того или иного стекла; лучше брать
  разные ракурсы, чтобы показать масштаб проекта и красоту стеклянных конструкций.
- Предметная съёмка: фото или 3D-визуализация с акцентом на продукт, максимально естественно
  передающая реальное стекло.
- Производство: рабочие процессы, люди за работой.
- Жизненная ситуация: в разных формах показывает преимущества стекла (энергоэффективность,
  комфорт, приватность, отсутствие бликов). Люди на фото дружелюбны, благополучны, в движении
  или развитии и располагают к себе.

## Как описывать картинку для генерации
Шаблон описания изображения для поста САЛАВАТСТЕКЛО:
«Фотореалистичный снимок: [жанр — архитектурный объект / предметная съёмка / производство /
жизненная ситуация], [сюжет], чистое стекло без пятен и искажений, естественный дневной свет,
холодная гамма с доминированием Petrol #196C7F и светло-серых #C1D0D3, #DDE1E1, без текста,
без логотипов и надписей». Логотип и товарный знак на картинке не генерировать никогда: его
ставит дизайнер по оригинальному макету.

## Рекламный макет: принцип построения
Стр. 44. Логотип размещается слева сверху с учётом охранного поля. Заголовок и подзаголовок
отделяются от логотипа узкой прямой линией и выравниваются по левому краю под логотипом.
Единый стиль макетов подчёркивает единство фирменного стиля. Пример — макет Clearview: логотип,
линия, название продукта, фото архитектуры, пиктограммы свойств.
