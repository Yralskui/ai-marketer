# Реализованные функции и ограничения

Документ для сдачи (п. 8.4 ТЗ). Состояние на 13.11.2026. Пункты, которые ещё в работе у потока A
(реальная LLM, картинки, ChatGPT), отмечены ⏳.

## Что умеет AI-маркетолог

### Работа с клиентом в Telegram
- Задачи обычным языком: «напиши пост про акцию с картинкой», «сделай пост #3 короче»,
  «покажи мои посты», «сделай отчёт». Агент сам выбирает действие и помнит историю диалога
  по каждой компании.
- Меню кнопками под полем ввода, приветствие с картинкой, описание бота в пустом чате.
- Онбординг: рассказ текстом, файлы PDF/DOCX/TXT и ссылка на сайт → профиль компании (продукты,
  аудитория, преимущества, тон, запреты). Профиль используется во всех текстах.

### Контент и согласование
- Черновик поста с картинкой. В карточке — **текст, площадка (канал) и время публикации**.
- Кнопки: ✅ Опубликовать · 🕒 Запланировать («завтра в 10 утра») · ✏️ Изменить (с комментарием)
  · ❌ Отклонить.
- **Без одобрения публикации нет**: у агента нет инструмента публикации, статус «одобрен» ставит
  только кнопка. После правки пост снова идёт на согласование. Правило сторожат тесты.
- Публикация в Telegram-канал сразу или по расписанию. Двойной клик не публикует пост дважды.
  При временных сбоях Telegram (429, 5xx) — автоповтор, о неудаче уведомляются ответственный и
  администратор.

### Комментарии
- Комментарии из группы обсуждения канала: AI готовит ответ по профилю компании и тексту поста и
  присылает карточку «Отправить / Свой ответ / Пропустить».
- Автоответ — только по отдельному разрешению администратора (`/autoreply on`). Жалобы, возвраты
  и вопросы о заказах всегда идут человеку.

### Аналитика и отчёты
- Реакции на посты (Telegram присылает их боту-администратору канала), комментарии,
  согласования, расходы на AI.
- Отчёт `/report` и кнопка «📈 Отчёт»: цифры, график, **выводы, гипотезы и рекомендуемые
  действия**.
- Автоматически по расписанию (понедельник 10:00; для демо — каждые N минут).

### Несколько компаний и администрирование
- Администратор (поставщик услуги) создаёт компанию в боте (`/new_company`) и выдаёт клиенту
  ссылку-приглашение. Программирование не нужно.
- У каждой компании свой профиль, материалы, посты, история диалога, канал, комментарии, отчёты,
  расходы и лимит. Клиент видит только свою компанию — проверено тестами.
- Учёт расходов на AI по компаниям (`/costs`), месячный лимит (`/budget`): при 80% —
  предупреждение, при 100% вызовы блокируются до траты денег.
- Журнал действий (`/log`), список клиентов и отзыв доступа (`/clients`). При отзыве старая
  ссылка-приглашение перестаёт работать.

### Надёжность
- Данные в SQLite: после перезапуска посты, расписание, компании и история на месте. Новые
  колонки добавляются в базу автоматически.
- Docker-образ с volume и автоперезапуском для работы 24/7 на сервере.
- 119 автотестов без сети и ключей, включая сквозной сценарий бота.

## Ограничения

| Ограничение | Причина | Что делать |
|---|---|---|
| ⏳ Тексты и картинки сейчас шаблонные (mock) | ключ LLM ещё не подключён (поток A) | подключить модель — см. [AI_OPTIONS.md](AI_OPTIONS.md) |
| Публикация только в Telegram | VK и MAX — заглушки (MVP допускает одну площадку) | публикаторы VK и MAX — в доработках |
| Нет просмотров постов | Bot API не отдаёт просмотры | MTProto-клиент от имени пользователя |
| Реакции видны, только если бот — админ канала | так устроен Telegram | указано в инструкции подключения |
| Комментарии — только при группе обсуждения | так устроен Telegram | указано в инструкции подключения |
| Незавершённый ввод (правка, время) теряется при перезапуске | FSM в памяти | Redis для FSM (B9) |
| Нет миграций для переименования колонок | хакатон | Alembic (B9) |
| На российском VPS нужен прокси для Telegram | api.telegram.org заблокирован | `TELEGRAM_PROXY` |
| ⏳ ChatGPT | подписка не даёт API, OpenAI из РФ напрямую недоступен | разбор и рабочий вариант — [AI_OPTIONS.md](AI_OPTIONS.md#chatgpt-что-реально-можно-сделать-критерий-12-тз) |
| Нет конкурентного анализа и сценариев видео | не успеваем к MVP | в доработках |
