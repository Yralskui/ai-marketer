# ВКонтакте в Mini App

Адаптер перенесён из ветки [feature/miniapp-analytics](https://github.com/Yralskui/ai-marketer/commits/feature/miniapp-analytics).

1. Добавьте в локальный `.env` строку `VK_COMMUNITIES=<числовой id сообщества>:<ключ>`.
   Несколько пар разделяются запятой. Ключи остаются в окружении сервера.
2. Пересоздайте контейнер бота. В редакторе профиля укажите ссылку на сообщество или
   его ID. Сообщество привязывается к одному профилю.
3. В чате попросите пост для ВКонтакте, Telegram или для обеих площадок. При
   согласовании можно опубликовать сразу или оставить запланированное время.
   Из истории Telegram-поста можно сделать отдельный черновик для ВКонтакте.

С ключом сообщества доступны публикация текста и замеры подписчиков. Для лайков и
комментариев включите у сообщества Long Poll API и события новых, изменённых,
удалённых и восстановленных комментариев к записи, добавления и удаления отметок
«Нравится».

С токеном администратора с нужными правами задайте `VK_IS_BUSINESS_ACCOUNT=true`.
Это включает фото, замеры просмотров и репостов, сверку лайков и комментариев и
правку текста опубликованной записи. Медиаальбомы передают во ВКонтакте фотографии.
О пропущенных вложениях приложение сообщает после публикации.
