# ВКонтакте

Третий слой (адаптеры соцсетей): публикация записей в сообщество, правка опубликованных,
число подписчиков и просмотры под записями. Telegram и ВКонтакте работают параллельно, у
каждой компании может быть свой канал в обеих сетях.

## Что умеет

| Возможность | Как работает |
|---|---|
| Публикация текста и картинки | `wall.post` от имени сообщества; картинка загружается через `photos.getWallUploadServer` → `photos.saveWallPhoto` |
| Защита от дубля | у записи свой `guid`: ВК не принимает вторую запись с тем же значением в течение часа |
| Правка опубликованной записи | `wall.edit`; картинка записи сохраняется (прежние вложения передаются заново) |
| Подписчики сообщества | `groups.getById` → `members_count`, раз в час (общий сбор метрик) |
| Просмотры и репосты записей | `wall.getById` → `views`, `reposts`, раз в час; удалённые записи помечаются |
| Диагностика | тип сообщества, число подписчиков, закрыта ли стена |

Публикация, как и в Telegram, возможна **только после согласования** кнопкой в Mini App.
Правка уже опубликованной записи — отдельное явное действие человека; у агента такого
инструмента нет.

## Какое сообщество нужно

Нужно **сообщество с лентой новостей**: публичная страница или «Бизнес» (в API это
`type=page`). Записи такого сообщества выходят в ленту подписчиков. «Группа по интересам»
(`type=group`) — это чат с участниками; публиковать в неё тоже можно, но «Диагностика» в Mini App
предупредит, что для ленты лучше публичная страница.

## Настройка

1. **Создайте сообщество** типа «Публичная страница» или «Бизнес» и откройте стену.
2. **Ключ доступа:** Управление → Работа с API → Ключи доступа → «Создать ключ». Права:
   стена, фотографии, управление сообществом.
3. **Числовой id сообщества.** Если у сообщества адрес `vk.com/club123456`, id — `123456`.
   Для короткого адреса узнать id можно запросом (подставьте имя и ключ):
   `https://api.vk.com/method/groups.getById?group_id=<имя>&access_token=<ключ>&v=5.199`
4. **Сервер:** в `.env` добавьте строку и перезапустите бота (`docker compose up -d`):

   ```
   VK_COMMUNITIES=123456:vk1.a.xxxxxxxx
   ```

   Несколько сообществ — через запятую: `123456:ключ1,789012:ключ2`. Ключи — секреты, они
   хранятся только в `.env`; в базе лежат лишь id и название сообщества.
5. **Mini App:** Компания → чип «Подключить ВК» → ссылка на сообщество → «Проверить и
   подключить». Подойдёт `https://vk.com/название`, `club123`, `public123` или число.

> Если ВК ответит ошибкой 27 («метод недоступен с ключом сообщества») при загрузке картинки,
> используйте вместо ключа сообщества **токен пользователя-администратора** с правами `wall`,
> `photos`, `groups`, `offline`. Остальное (`from_group=1`) работает и с ним.

## Как пользоваться

- **Копия поста для ВК.** В карточке поста кнопка «Копия для ВК» создаёт отдельный черновик
  для ВКонтакте с тем же текстом и картинкой. Он идёт на согласование, как любой другой.
- **Публикация** — «Опубликовать сейчас» или «Запланировать» в карточке ВК-поста.
- **Правка живой записи.** «История» → у записи ВК кнопка «Изменить текст во ВКонтакте».
  Новый текст меняется и во ВКонтакте, и у нас (версия сохраняется в «Версиях поста»).
- **Подписчики и просмотры.** «Аналитика» показывает графики по каждому каналу: Telegram и
  сообщество ВК отдельными линиями; просмотры и пересылки (репосты) записи — после выбора поста.

## Ошибки, которые вы можете увидеть

| Что показывает бот | Причина и что делать |
|---|---|
| «для сообщества … не задан ключ доступа» | нет записи в `VK_COMMUNITIES` — добавьте и перезапустите |
| «ключ доступа недействителен или отозван» (код 5) | создайте новый ключ |
| «метод недоступен с ключом сообщества» (27) | нужен токен администратора, см. выше |
| «публиковать на стене сейчас нельзя…» (214) | закрытая стена или лимит публикаций |
| «достигнут суточный лимит публикаций» (224) | подождать до следующих суток |
| «нет связи с ВКонтакте… запись могла выйти» | проверьте стену сообщества, прежде чем нажимать «Повторить» |

Временные ошибки лимита запросов (6 и 9) повторяются сами. Запись на стену после сетевого
сбоя **не** отправляется повторно автоматически: она могла дойти, повтор дал бы дубль.

## Для разработчиков

- `app/publishers/vk_api.py` — клиент API (лимит ~3 запросов/с, повторы, загрузка фото);
- `app/publishers/vk.py` — `VKPublisher`: `publish`, `edit`, `check_channel`, `resolve`;
- `app/publishers/vk_analytics.py` — `VKAnalytics` (интерфейс `AnalyticsSource`);
- `app/services/vk_channel.py` — подключение и отключение сообщества;
- `PublishingService.edit_published` и `posts.clone_for_platform` — общие сервисы;
- в `Publisher` (`publishers/base.py`) добавлен **необязательный** метод `edit`: по умолчанию
  «не поддерживается», поэтому Telegram и остальные публикаторы не менялись. Машина состояний
  поста не тронута: правка опубликованного не меняет статус `published`.

Тесты (`tests/test_vk.py`) идут на подделанном ВК (`FakeVK`, `httpx.MockTransport`):
порядок вызовов, повторы, ошибки, правка с сохранением картинки, сбор метрик в базу и
весь путь через Mini App.

**Что не проверено:** работа с настоящим ключом ВК. Первый боевой прогон — подключить
сообщество, опубликовать пробный пост с картинкой, поправить его и дождаться почасового сбора
метрик.
