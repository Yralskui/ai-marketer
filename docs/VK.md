# ВКонтакте

Третий слой (адаптеры соцсетей): публикация записей в сообщество, правка опубликованных,
число подписчиков и просмотры под записями. Telegram и ВКонтакте работают параллельно, у
каждой компании может быть свой канал в обеих сетях.

## Какой ключ — что умеет (проверено на живом ключе сообщества, 14.11.2026)

ВКонтакте сильно ограничивает ключи сообществ: это не «бот с полным доступом», как в Telegram,
а урезанный ключ. Что мы проверили на настоящем ключе:

| Возможность | Ключ сообщества | Токен администратора |
|---|---|---|
| Публикация текста (`wall.post`) | ✅ | ✅ |
| Подписчики (`groups.getById`) | ✅ | ✅ |
| Картинки к записям | ❌ (см. ниже) | ✅ |
| Правка опубликованного (`wall.edit`) | ❌ ошибка 27 | ✅ |
| Просмотры и репосты (`wall.getById`) | ❌ ошибка 27 | ✅ |

**Картинки с ключом сообщества: все обходные пути проверены и закрыты.**

| Способ | Результат |
|---|---|
| `photos.getWallUploadServer` (обычная загрузка на стену) | ошибка 27 |
| «Фото сообщений» (`photos.getMessagesUploadServer`) | ВК принимает запись без ошибки, но **молча выбрасывает картинку** |
| Ссылка вложением (карточка) | ВК отвергает: `link_photo_sizing_rule, No photo given`; `wall.parseAttachedLink` — 27 |
| Ссылка в тексте записи | остаётся обычной ссылкой, карточка не строится |
| Документы (`docs.getWallUploadServer`) | отказ 15: в сообществе выключен раздел «Документы» (не проверено после включения) |

Что делает бот с ключом сообщества:
- **картинка:** пост выходит **текстом** с жёлтым пояснением «Пост вышел без картинки…»;
  ошибка 27 запоминается, чтобы не тратить лишний запрос на каждый пост;
- **правка:** понятная ошибка «нужен токен администратора», пост не меняется;
- **просмотры:** раз в час в логе предупреждение, график подписчиков при этом строится;
- «Диагностика» в Mini App называет тип ключа и перечисляет, что он не умеет.

### Как получить картинки, правку и просмотры: токен администратора

Нужен токен **пользователя, который администрирует сообщество**, с правами `wall`, `photos`,
`groups`, `offline`. На нашей стороне ничего менять не надо: такой токен вписывается в тот же
`VK_COMMUNITIES=<id>:<токен>` вместо ключа сообщества, и бот сам переходит на настоящие фото.

Классический путь (не проверен в 2026 году: по отзывам ВК мог закрыть `oauth.vk.com`, тогда
нужен VK ID на `id.vk.com`, приложения которого требуют одобрения):
1. Создать Standalone-приложение на `vk.com/editapp?act=create` и взять его ID (в адресе
   `vk.com/editapp?id=<ID>`).
2. Открыть в браузере, где вы вошли как администратор сообщества:
   `https://oauth.vk.com/authorize?client_id=<ID>&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=wall,photos,groups,offline&response_type=token&v=5.199`
3. Разрешить доступ. В адресной строке появится `#access_token=…` — это и есть токен.

Токен пользователя даёт доступ ко всему, что разрешено правами, поэтому храните его только в
`.env`, а отозвать можно в настройках ВК → Безопасность → Приложения. Если способ не
сработает, остаётся письмо в поддержку API ВК (`devsupport@corp.vk.com`).

Публикация, как и в Telegram, возможна **только после согласования** кнопкой в Mini App.
Правка уже опубликованной записи — отдельное явное действие человека; у агента такого
инструмента нет.

## Какое сообщество нужно

Любое сообщество ВКонтакте, стена которого не выключена и не закрыта: записи выходят от имени
сообщества в ленту подписчиков. Тип в API у новых сообществ — `group` (так отвечает и
«Бизнес»); «Диагностика» показывает «сообщество». Выключенную или закрытую стену бот
отклонит при подключении.

## Настройка

1. **Создайте сообщество** и откройте стену (достаточно «ограниченной»: публикуют только админы).
2. **Ключ доступа:** Управление → Настройки → Работа с API → Ключи доступа → «Создать ключ».
   Права: управление сообществом, фотографии, стена.
3. **Числовой id сообщества.** Если у сообщества адрес `vk.com/club123456`, id — `123456`.
   Для короткого адреса узнать id можно запросом (подставьте имя и ключ):
   `https://api.vk.com/method/groups.getById?group_id=<имя>&access_token=<ключ>&v=5.199`
4. **Сервер:** в `.env` добавьте строку и перезапустите бота (`docker compose up -d`):

   ```
   VK_COMMUNITIES=123456:vk1.a.xxxxxxxx
   ```

   Несколько сообществ — через запятую: `123456:ключ1,789012:ключ2`. Ключи — секреты, они
   хранятся только в `.env`; в базе лежат лишь id и название сообщества.
5. **Mini App:** Компания → чип «Подключить ВК» → ссылка на сообщество → «Проверить и
   подключить». Подойдёт `https://vk.com/название`, `https://vk.ru/club123`, `club123` или число.

## Как пользоваться

- **Копия поста для ВК.** В карточке поста кнопка «Копия для ВК» создаёт отдельный черновик
  для ВКонтакте с тем же текстом и картинкой. Он идёт на согласование, как любой другой.
- **Публикация** — «Опубликовать сейчас» или «Запланировать» в карточке ВК-поста.
- **Правка живой записи.** «История» → у записи ВК кнопка «Изменить текст во ВКонтакте».
  Новый текст меняется и во ВКонтакте, и у нас (версия сохраняется в «Версиях поста»).
- **Подписчики и просмотры.** «Аналитика» показывает графики по каждому каналу: Telegram и
  сообщество ВК отдельными линиями; просмотры и пересылки (репосты) записи — после выбора поста.

## Ошибки, которые вы можете увидеть

| Что показывает бот | Причина и что делать |
|---|---|
| «для сообщества … не задан ключ доступа» | нет записи в `VK_COMMUNITIES` — добавьте и перезапустите |
| «ключ доступа недействителен или отозван» (код 5) | создайте новый ключ |
| «метод недоступен с ключом сообщества» (27) | это ограничение ВК для ключей сообществ: нужен токен администратора, см. таблицу выше |
| «публиковать на стене сейчас нельзя…» (214) | закрытая стена или лимит публикаций |
| «достигнут суточный лимит публикаций» (224) | подождать до следующих суток |
| «нет связи с ВКонтакте… запись могла выйти» | проверьте стену сообщества, прежде чем нажимать «Повторить» |

Временные ошибки лимита запросов (6 и 9) повторяются сами. Запись на стену после сетевого
сбоя **не** отправляется повторно автоматически: она могла дойти, повтор дал бы дубль.

## Для разработчиков

- `app/publishers/vk_api.py` — клиент API (лимит ~3 запросов/с, повторы, загрузка фото);
- `app/publishers/vk.py` — `VKPublisher`: `publish`, `edit`, `check_channel`, `resolve`;
- `app/publishers/vk_analytics.py` — `VKAnalytics` (интерфейс `AnalyticsSource`);
- `app/services/vk_channel.py` — подключение и отключение сообщества;
- `PublishingService.edit_published` и `posts.clone_for_platform` — общие сервисы;
- в `Publisher` (`publishers/base.py`) добавлен **необязательный** метод `edit`: по умолчанию
  «не поддерживается», поэтому Telegram и остальные публикаторы не менялись. Машина состояний
  поста не тронута: правка опубликованного не меняет статус `published`.

Тесты (`tests/test_vk.py`) идут на подделанном ВК (`FakeVK`, `httpx.MockTransport`):
порядок вызовов, повторы, ошибки, правка с сохранением картинки, сбор метрик в базу и
весь путь через Mini App.

**Что проверено вживую (ключ сообщества, 14.11.2026):** подписчики; публикация текста и
картинок — все обходные пути для картинок (таблица выше); что `wall.edit`, `wall.delete`,
загрузка фото и чтение стены ключу закрыты (ошибка 27).

**Что не проверено:** работа с токеном администратора (картинки, правка, просмотры) и документы
после включения раздела.
