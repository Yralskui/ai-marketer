## Подготовка (за час до защиты)
1. На сервере в `/opt/ai-marketer/.env`: `LLM_PROVIDER=openai`, ключ, `IMAGE_PROVIDER` (после A2),
   `ENABLE_WEEKLY_REPORT=true`, `REPORT_INTERVAL_MINUTES=5`, `PUBLISH_DRY_RUN=false` →
   `docker compose up -d`.
2. Компания «Салаватстекло»: «➕ Новая компания» → «🎨 Бренд-гид» → «Шаблон: Салаватстекло» →
   «📚 Материалы» → текст из `content/salavatsteklo/about.md` → «Готово».
3. Демо-канал: бот — админ; привязана группа обсуждения, бот в ней админ.
4. Второй Telegram-аккаунт — «клиент» (для приглашения) и «подписчик» (для комментария).
5. Прогнать сценарий целиком один раз, удалить тестовые посты из канала.
6. Запасной план: если OpenAI недоступен — бот в mock-режиме проходит весь сценарий (тексты
   шаблонные). Откат кода — тег `v1-monolith`.

## Сценарий

**1. Администратор подключает компанию (критерии 11, 3) — 1 мин.**
«🗂 Компании» → «Салаватстекло»: профиль, бренд-гид (написание MultiComfort°, цвета Petrol,
фотостиль). Пояснить: всё настроено кнопками, без кода; брендбук → бренд-гид.

**2. Канал одной кнопкой (критерий 7) — 30 с.**
«📣 Канал» → «Выбрать канал»: Telegram сам выдаёт боту права.

**3. Задача обычным языком (критерии 1, 4) — 1 мин.**
«✍️ Новый пост» → «стекло MultiComfort° Light Blue для фасадов бизнес-центров, с картинкой».
Черновик выглядит ровно как пост в канале; в карточке — куда и когда.

**4. Доработка (критерий 5) — 1 мин.**
«✏️ Изменить» → «Короче» → новая версия на согласование. «🖼 Своё фото» → фото фасада → пост снова
на согласовании. Если в тексте нарушено написание — «⚠️ Проверка бренд-гида» и «🛠 Исправить».

**5. Публикация и запрет без согласия (критерии 6, 7) — 1 мин.**
Отклонить один черновик — в канале ничего. Опубликовать другой — пост в канале, карточка
обновилась: «Открыть в канале» / «Удалить из канала».

**6. Расписание — 30 с.** «🕒 Запланировать» → «Завтра 10:00».

**7. Контекст и знания (критерии 2, 3) — 1 мин.**
«что ты знаешь о нашей компании?» → факты из профиля. «сделай пост #N официальнее» — агент
помнит, о каком посте речь.

**8. Вторая компания и изоляция (критерии 9, 11) — 1,5 мин.**
`/new_company Кофейня` → ссылка-приглашение → второй аккаунт входит → видит только свою компанию,
посты Салаватстекла недоступны; «📊 Состояние» без технических деталей.

**9. Автономная задача (критерий 8) — 1 мин.**
Приходит отчёт по расписанию: цифры, график в фирменных цветах, выводы, гипотезы, действия.
Комментарий подписчика под постом → карточка с готовым ответом.

**10. Надёжность (критерий 10) — 30 с.**
`docker compose restart bot` → бот отвечает, посты и компании на месте. Показать `/costs`.

**11. ChatGPT (критерий 12) — 1 мин.**
Честно: подписка ChatGPT ≠ API; работаем через OpenAI API с прокси (сервер в РФ), запросы
повторяются при сбоях. Показать вариант с аккаунтом ChatGPT по итогам A3.
