# Чек-лист функций: что не должно потеряться при переходе на новую архитектуру

Рабочая версия до перестройки — тег **`v1-monolith`** (`git checkout v1-monolith`). Она же
развёрнута на сервере 13.11.2026. Перед заменой `main` новая ветка должна пройти **каждый пункт**
ниже. Где есть автотест — он указан; остальное проверяется руками в Telegram.

Обозначения: 🧪 — есть автотест, 👆 — проверка руками.

## 1. Доступ и компании (критерии 9, 11)
- [ ] Администраторы — из `ALLOWED_USER_IDS`; посторонний получает отказ со своим ID. 🧪 `test_bot_flow`
- [ ] `/new_company` создаёт компанию и выдаёт ссылку-приглашение `t.me/<bot>?start=<код>`. 🧪
- [ ] Клиент по ссылке видит только свою компанию: посты, профиль, историю, фото, комментарии. 🧪 `test_companies`
- [ ] Кнопки под чужим постом у клиента не работают; администратор может работать с любым. 🧪
- [ ] `/companies`, `/use N` — переключение компаний у администратора. 🧪
- [ ] `/invite new` меняет код, старая ссылка перестаёт работать. 🧪
- [ ] `/clients` — отключение и возврат доступа клиента (со сменой приглашения). 🧪
- [ ] История агента разделена по компаниям. 🧪

## 2. Посты и согласование (критерии 4–7)
- [ ] Черновик с кнопками: Опубликовать · Запланировать · Изменить · Своё фото · Отклонить. 🧪
- [ ] Карточка показывает канал и время публикации (п. 3.5 ТЗ). 🧪 `test_companies`
- [ ] **Без одобрения публикации нет**: у агента нет инструмента публикации, статусы — только через
      `services/approval.py`, `ensure_publishable()`. 🧪 `test_post_state_machine`
- [ ] После правки или замены фото пост снова уходит на согласование. 🧪 `test_media`
- [ ] Быстрые правки («Короче», «Эмодзи», «Другой вариант»…) и своя правка текстом. 🧪
- [ ] Быстрое время («Завтра 10:00»…) и своё время текстом («в пятницу в 18:00»). 🧪 `test_ux`, `test_timeparse`
- [ ] Карточка обновляется на месте: «Опубликован» + «Открыть в канале» / «Удалить из канала». 🧪
- [ ] Двойной клик не публикует дважды; захват поста в БД. 🧪 `test_publish_reliability`
- [ ] Повтор при 429/5xx Telegram, без повтора при сетевом сбое (нет дублей). 🧪
- [ ] При ошибке публикации — кнопка «🔁 Повторить», уведомление администратору. 🧪
- [ ] Посты по расписанию публикуются планировщиком раз в минуту. 🧪 `test_scheduler_jobs`

## 3. Канал (критерий 7)
- [ ] «📣 Канал» → «Выбрать канал» (нативная кнопка Telegram, бот сразу получает права). 🧪
- [ ] `/channel @канал` вручную; проверка прав бота. 🧪
- [ ] У каждой компании свой канал. 🧪

## 4. AI и бренд (критерии 1–4)
- [ ] OpenAI через `LLM_PROXY` (несколько прокси через запятую, смена маршрута). 🧪 `test_openai_resilience`
- [ ] Повторы «до конца» в пределах `LLM_RETRY_BUDGET_SECONDS`; 401/403 — понятная ошибка. 🧪
- [ ] Учёт токенов и рублей по компаниям, `/costs`, лимит `/budget` (80% — предупреждение,
      100% — блок до траты). 🧪 `test_usage`
- [ ] Бренд-гид в каждом промпте (через профиль) и в описании картинки. 🧪 `test_brand`
- [ ] Шаблон «Салаватстекло», загрузка брендбука/правил, проверка поста и «🛠 Исправить». 🧪
- [ ] Онбординг: текст, PDF/DOCX/TXT, сайт → профиль. 🧪 `test_profile_and_mocks`, `test_documents`

## 5. Фото, комментарии, отчёты
- [ ] Фото в личку → фотобанк; с подписью — сразу пост; «🖼 Фотобанк». 🧪 `test_media`
- [ ] Комментарии из группы обсуждения → карточка «Отправить / Свой ответ / Пропустить». 🧪 `test_comments`
- [ ] Автоответ только по `/autoreply on`; жалобы всегда человеку. 🧪
- [ ] Реакции на посты сохраняются (`message_reaction_count`). 🧪 `test_reports`
- [ ] Отчёт: цифры, график, выводы/гипотезы/действия; по расписанию и кнопкой. 🧪
- [ ] Журнал `/log`. 🧪

## 6. Интерфейс
- [ ] Меню кнопками; у администратора — свой ряд (компании, приглашение, клиенты, расходы, журнал,
      бренд-гид). 🧪
- [ ] Приветствие с картинкой, описание бота, аватарка ставится сама, если её нет. 🧪
- [ ] «📊 Состояние» без техники для клиента, диагностика для администратора. 🧪 `test_ux`
- [ ] Посты кнопками с фильтрами. 🧪

## 7. Надёжность и деплой (критерий 10)
- [ ] Docker: volume `ai-marketer-data`, `restart: unless-stopped`, после рестарта данные на месте. 👆
- [ ] Новые колонки SQLite добавляются сами (автомиграция). 🧪
- [ ] `TELEGRAM_PROXY` — бот работает с VPS в РФ. 🧪
- [ ] Секреты только в `.env`, в Git нет ключей и `data/`. 👆

## Как проверить ветку перед заменой `main`
```bash
git fetch origin && git switch <ветка>
ruff check . && ruff format --check . && pytest && python -m app.main --check
```
Если тесты переписаны под новую структуру, их число не должно стать меньше без объяснения:
на `v1-monolith` — **147 тестов**.
