# Как подключить новую компанию

Подключение делается целиком в Telegram, без программирования и без перезапуска бота.
Делает его администратор: человек, чей Telegram ID указан в `ALLOWED_USER_IDS`.

## 1. Создать компанию

Напишите боту:

```
/new_company Цветочный салон «Роза»
```

Бот создаст компанию, переключит вас на неё и пришлёт ссылку-приглашение для клиента.
Всё, что вы делаете дальше (онбординг, посты, канал), относится только к этой компании.

## 2. Загрузить сведения о компании

```
/onboarding
```

Отправьте боту материалы: текст о компании, файлы (PDF, DOCX, TXT, MD — прайс, меню, презентация)
и ссылку на сайт. Потом нажмите «Готово» или `/done`, и AI составит профиль: продукты,
аудиторию, преимущества, тон. Посмотреть результат можно командой `/profile`.

Это может сделать и сам клиент после подключения.

### Загрузка больших документов

До 20 МБ на файл можно отправлять прямо в Telegram. Для более крупного файла бот выдаёт
ссылку на форму, если задан `UPLOAD_PUBLIC_URL`. Ссылку также можно запросить командой
`/upload` во время онбординга. Поддерживаются PDF, DOCX, TXT и MD. Бот сохраняет оригиналы в каталоге
`data/documents/<id компании>/` для последующей обработки.
Лимит — **100 МБ исходных файлов суммарно на профиль**. Для материалов, загруженных
старой версией, исходный размер неизвестен и используется размер извлечённого текста.

Ссылка действует 10 минут и расходуется при начале авторизованной загрузки. Новая ссылка
отменяет предыдущую. При смене профиля, отзыве доступа или перезапуске бота запросите
ссылку заново. Бот подтверждает успешное сохранение файла.

Для Mac укажите `UPLOAD_PUBLIC_URL=http://localhost:8080` и открывайте ссылку в браузере
на том же Mac. Для телефона или VPS укажите публичный HTTPS-адрес обратного прокси к
`127.0.0.1:8080`. Проксируйте только `/upload`, `/upload.css` и `/upload.js`. Для
`POST /upload` установите лимит тела 100 000 000 байт, ограничьте частоту запросов и
отключите буферизацию загрузки. Разрешите до 120 секунд на передачу и небольшой запас на сохранение. Исключите заголовок Authorization из логов.

## 3. Подключить Telegram-канал компании

1. Добавьте бота в канал компании администратором с правом «Публикация сообщений».
2. Напишите боту:
   ```
   /channel @username_канала
   ```
   Для приватного канала укажите его числовой ID вида `-100XXXXXXXXXX`. Ссылка
   `t.me/username` тоже подойдёт.
3. Бот сохранит канал и сразу проверит права. Нужна отметка «✅ бот — администратор».

## 3а. Подключить комментарии (по желанию)

1. Канал → Управление каналом → **Обсуждение** → привяжите группу (или создайте новую).
2. Добавьте бота в эту группу **администратором**.
3. `/comments` покажет «Группа обсуждения: подключена ✅». На каждый комментарий под постом
   бот пришлёт черновик ответа с кнопками.
4. Автоответ на обычные комментарии без согласования включает администратор:
   `/autoreply on`. Жалобы и вопросы о деньгах всё равно придут на согласование.

## 4. Пригласить клиента

Отправьте клиенту ссылку из шага 1. Если она потерялась, её снова покажет `/invite`.

Клиент открывает ссылку и нажимает «Запустить». Дальше:
- он видит только свою компанию: профиль, посты, историю диалога;
- черновики на согласование и уведомления о публикациях приходят ему;
- ставить задачи он может обычным текстом: «напиши пост про букеты к 8 марта с картинкой».

Если ссылка попала не тому человеку, выполните `/invite new`: старая ссылка перестанет
работать. Уже подключённые клиенты доступ при этом не теряют.

## 5. Переключение между компаниями

- `/companies` — список компаний с клиентами и каналами, кнопки для переключения.
- `/use N` — перейти к компании №N.
- `/status` — какая компания сейчас выбрана и всё ли в порядке с каналом.

Кнопки под черновиками работают у администратора для любой компании, даже если сейчас
выбрана другая.

## Что изолировано между компаниями

| Данные | Как разделено |
|---|---|
| Профиль и материалы | у каждой компании свои |
| Посты и статусы | клиент видит и согласует только посты своей компании |
| История диалога с AI | своя для каждой компании, в том числе у администратора |
| Канал публикаций | свой; пост компании уходит только в её канал |
| Уведомления | приходят ответственному за компанию (клиенту) |

Изоляцию проверяют тесты `tests/test_companies.py` и сценарий в `tests/test_bot_flow.py`.
