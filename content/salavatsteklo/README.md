# Пакет данных: Салаватстекло (профиль по умолчанию)

Данные для «профиля по умолчанию» — компании, с которой бот готов работать сразу после запуска.
Это **данные, а не код**: их можно подключить в любую архитектуру (монолит `v1-monolith` или
новую структуру потока A).

Источник — брендбук АО «Салаватстекло» от 15.11.2023 (Google Диск, передан организаторами).
Формулировки пересказаны своими словами, факты не додумывались. Что не нашлось в брендбуке —
помечено «уточнить».

| Файл | Что внутри | Куда подключается |
|---|---|---|
| `profile.json` | профиль компании в формате `BusinessProfile` (`app/services/business_profile.py`) | `Business.profile` |
| `brand_guide.json` | бренд-гид в формате `BrandGuide` (`app/services/brand.py`), то же, что шаблон `brand_presets.SALAVATSTEKLO` | `Business.settings.brand_guide` |
| `about.md` | факты о компании, история, миссия, видение, ценности — для онбординга/RAG | загрузить как материал (`sources`) |
| `example_posts.md` | эталонные посты в стиле бренда — для few-shot в промпте и для демо | промпт `write_post` / демо |
| `image_prompts.md` | описания картинок в фотостиле бренда | генерация картинок / демо |

## Как подключить сейчас (в текущем боте)
1. «🗂 Компании» → «➕ Новая компания» → `Салаватстекло`.
2. «🎨 Бренд-гид» → «✨ Шаблон: Салаватстекло».
3. «📚 Материалы» → отправить текст из `about.md` → «Готово» — профиль соберётся сам.
4. «📣 Канал» → «Выбрать канал».

Автоматическое создание этой компании при первом запуске — задача на новую архитектуру
(после слияния ветки потока A).

## Ограничения
- Брендбук свёрстан картинками: текста в PDF нет. Для RAG по нему нужно «зрение» модели или
  ручная выжимка (она здесь).
- Брендбук весит 55 МБ — через Telegram-бота не загрузить (лимит 20 МБ), нужен Mini App.
- Логотип в материалах бота не используется: по брендбуку это требует согласования.
